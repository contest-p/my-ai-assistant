# 시나리오.md — 전역 후 1년, 내 소비를 아는 AI 비서

## 0. 한 줄 요약
KB국민은행 거래내역(전역일 2025.08.18 ~ 2026.08.18, 1,116건)을 기반으로,
지난 1년간의 소비/저축 패턴을 이해하고 대화형으로 답해주는 AI 비서.

## 1. 데이터 소스
- 원본: KB_거래내역조회 엑셀
- 기간: 2025.08.18 ~ 2026.08.18 (정확히 전역 후 1년)
- 건수: 1,116건 (출금 862건 / 입금 254건)
- 원본 컬럼: 거래일시, 적요(거래유형), 보낸분/받는분, 송금메모, 출금액, 입금액, 잔액, 거래점
- 주요 거래유형: 체크카드(601), 오픈뱅킹출금(216), 전자금융(210), 급여입금(3) 등

## 2. 페르소나
전역 후 사회 복귀를 준비 중인 사용자 본인. 지난 1년간 카드/이체로 흩어져 있던
소비 기록을 한눈에 돌아보고, 앞으로 지출 습관을 어떻게 바꿀지 감을 잡고 싶어함.

## 3. 핵심 시나리오 (기능별)

### 3-1. 데이터 기반 AI 채팅

**기본 — 요약 정보(기간/개수/평균·최대·최소/추세/이번 달)만으로 답변 가능**
- "전역하고 나서 지금까지 총 얼마 썼어?"
- "이번 달 지출이 평소보다 많은 편이야, 적은 편이야?" (PRD `current_month` 필드로 지원)
- "월별로 지출 추세가 어떻게 변했는지 알려줘"
- "입금이랑 지출 비교하면 저축은 잘 하고 있는 편이야?"
  (⚠ 원래 보너스로 분류했었는데 재검토 결과 `total_income`/`total_expense`/`net`이
  애초에 기본 요약 안에 있어서 재분류함 — Function Calling 없이도 답변 가능)

**보너스 — 소비 흐름을 직접 살펴보기**
- 월별 수입·지출 그래프와 순저축률로 소비 패턴 확인
- 전체/최근 6개월/최근 3개월을 선택해 비교
- 선택 기간 거래를 CSV·JSON으로 다운로드
- 다크 모드로 전환하고 다음 접속에서도 선택 유지

### 3-2. 데이터 관리 (CRUD)
- 전체 거래 목록을 훑어보며 확인 (조회)
- 카드 내역이 며칠 늦게 반영될 때 수동으로 지출 항목 추가
- 메모가 잘못 들어간 거래 수정
- 중복 입력되거나 테스트용으로 넣은 거래 삭제

### 3-3. 대화 기록 저장 / 불러오기
- "지난번에 물어봤던 지출 분석 다시 보고 싶어" → 대화 목록에서 선택해 불러오기
- 대화를 이어서 추가 질문하기

### 3-4. 배포 및 문서화
- 이 시나리오 자체와는 직접 관련 없음 — 8단계(배포)에서 별도로 다룸

## 4. 데이터 매핑 초안 (참고용 — 정식 스키마는 2단계 PRD.md에서 확정)
- date ← 거래일시
- value ← 입금액 − 출금액 (수입은 +, 지출은 −)
- memo ← 적요 + 보낸분/받는분 (예: "체크카드 / 씨유(CU)진해장천대")

⚠ 검토 필요: 거래건별 순액은 값이 들쭉날쭉해서(커피 한 잔 vs 월급 입금) "최근 추세" 계산이
매끄럽게 안 나올 수 있음. 2단계 PRD에서 아래 대안을 비교해서 결정:
  (A) 원본의 "잔액" 컬럼을 value로 사용 → 시간에 따른 잔고 증감 추세
  (B) 거래를 월별/주별로 집계한 순증감을 value로 사용

## 5. 유의사항
- 원본 엑셀에는 계좌번호·잔액·거래 상대방 실명 등 민감정보 포함
  → 원본 파일은 GitHub에 올리지 않고, 전처리된 파생 데이터만 저장소/DB에 사용
  → README 스크린샷에는 거래 상대방 이름 마스킹 처리
